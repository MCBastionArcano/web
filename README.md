## 🏰 Proyecto
Este repositorio contiene la página web oficial del **Bastión Arcano**, un servidor de Minecraft con temática medieval‑fantástica.  
Aquí encontrarás la estructura en **Markdown** y **Jekyll** para desplegar el sitio en GitHub Pages.

---

## 📂 Estructura
```
/web/
   index.md              ← Página principal
   reglas.md             ← Código de honor
   /assets/css/styles.css← Estilos personalizados
   /assets/img/logo.png  ← Logo del Bastión
   /_layouts/default.html← Layout base
_config.yml              ← Configuración Jekyll
```

---

## 🚀 Despliegue
1. Activa **GitHub Pages** en la configuración del repo.  
2. Selecciona la rama `main` y la carpeta `/web`.  
3. El sitio quedará disponible en:  
   `https://mcbastionarcano.github.io/web/`

---

## 🔧 Tecnologías
- Markdown para el contenido.  
- Jekyll para la generación estática.  
- GitHub Pages para el hosting.  
- Jenkins para automatizar el build y deploy.
